The Task APIs

Chrome ships small task-specific AI APIs that run on-device. Each demo below exercises one of them, with its own example. Nothing is sent to a server.

Needs Chrome 138 or newer on desktop · flags and hardware notes in the README

Availability model status & downloads

An API can be unavailable, downloadable, downloading or available. Models download once and stay on the machine. The browser only starts a download after a click.

Summarizer

One story, four summary types side by side — headline, teaser, tl;dr and key points — streaming as they generate.

Language Detector & Translator

Detect the language of a message with confidence scores, then translate it. Two APIs chained.

Writer & Rewriter

Draft a text from a brief with tone and length options, then push its tone in either direction.

Proofreader

Corrections with exact character ranges, marked in place, plus the fully corrected text.

Everything here runs locally through Chrome's built-in AI APIs · API documentation
